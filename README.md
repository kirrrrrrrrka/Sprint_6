# Sprint_6
## Автотесты для Яндекс.Самокат

Проект автоматизации тестирования сервиса Яндекс.Самокат с использованием Selenium, Pytest и Allure

## Структура проекта
- `pages/` - Page Object модели
- `tests/` - тестовые сценарии
- `conftest.py` - фикстуры Pytest
- `requirements.txt` - зависимости проекта
- `allure-report` - отчет allure_results
